# Project-Calculator

A browser-based calculator built as a part of The Odin Project course.

## About

This project is a functional calculator made with HTML, CSS and JavaScript. It can perform basic artihmetic operations and includes extra features such as decimal input, keyboard support, backspace, and divide-by-zero handling.

## Features

- Add, subtract, multiply, and divide
- Decimal support
- Clear and delete functionality
- Keyboard support
- Chained operations
- Rounded decimal results
- Divide-by-zero protection

## Built With

- HTML
- CSS
- JavaScript

## What I Learnt

While building this project, I practised:

- Working with DOM selectors and event listeners
- Updating the display based on user input
- Managing calculator state with variables
- Handling edge cases such as incompelte input and divide-by-zero
- using CSS Grid to build a calculator layout
- Adding keyboard interaction for better usability

## How to Run

1. Clone or download this repository
2. Open 'index.html' in your browser

## Project Structure

- 'index.html' - calculator layout
- 'styles.css' - calculator styling
- 'script.js' - calculator logic
